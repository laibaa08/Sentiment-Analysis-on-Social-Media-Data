This project focuses on performing sentiment analysis on Twitter data using the Kaggle Twitter Entity Sentiment Analysis dataset. The pipeline automatically detects the tweet text column, cleans the data by removing URLs, mentions, hashtags, and special characters, and then applies the VADER sentiment analyzer to classify tweets into positive, negative, or neutral categories. Both training and validation datasets are processed, and the results are saved as CSV files with added columns for cleaned text and predicted sentiment. This project demonstrates skills in Natural Language Processing (NLP), data preprocessing, and sentiment analysis while providing a foundation for further model evaluation and advanced machine learning approaches.
